# 🧪 BeautyShop – Manual QA Testing

Projekt portfolio przedstawiający **manualne testowanie formularza rejestracji użytkownika** na stronie **BeautyShop.pl**.

Celem projektu było sprawdzenie poprawności działania formularza rejestracji oraz walidacji danych w różnych scenariuszach, obejmujących zarówno **przypadki pozytywne, jak i negatywne**.

---

## 🎯 Cel projektu

Głównym celem testów było zweryfikowanie:

* poprawności działania formularza rejestracji,
* walidacji wprowadzanych danych,
* komunikatów wyświetlanych użytkownikowi,
* obsługi niepoprawnych danych,
* zachowania formularza w sytuacjach brzegowych.

---

## 🔍 Zakres testów

W ramach projektu przeprowadzono testy obejmujące m.in.:

* ✅ poprawną rejestrację użytkownika,
* 📧 walidację adresu e-mail,
* 🔐 walidację hasła oraz jego powtórzenia,
* ❌ puste i niepoprawne dane,
* ␣ spacje w polach formularza,
* 🇵🇱 polskie znaki,
* 📩 próbę rejestracji na istniejący adres e-mail,
* 📋 rejestrację bez akceptacji regulaminu.

Testy obejmowały zarówno **scenariusze pozytywne**, jak i **negatywne**, pozwalające zweryfikować poprawność walidacji formularza.
